# demo — 个税数据灌入 Excel 模板

把采集到的个税 JSON 数据灌入《个税退税计算模板.xlsx》，生成一份**保留全部公式**的已填充 Excel。

## 文件

| 文件 | 说明 |
|------|------|
| `tax_data.json` | 采集到的个税数据（来源：个税 APP 抓取） |
| `个税退税计算模板.xlsx` | 模板（原文件副本，公式都在 F/K/P/Q 列） |
| `fill_template.py` | 灌数脚本 |
| `output/个税退税计算表_已填充.xlsx` | 生成结果 |

## 用法

```bash
cd demo
python3 fill_template.py
# 或自定义路径：
python3 fill_template.py 数据.json 模板.xlsx 输出.xlsx
```

## 设计要点

1. **公式零修改**：模板里 F/K/P/Q 列以及第 29~42 行的税率/速算/应纳税额/退补公式一律保留不动，Excel 打开时自动重算。
2. **只写输入格**（模板里的淡蓝单元格）：
   - 收入、直接扣除（养老/医疗/失业/公积金/年金/捐赠/其他…）→ 金额直接写入 B/G/L 列；
   - 公式扣除（子女教育、赡养老人、房贷利息、住房租金…）→ 在模板固定基数下反推"月份数"，让公式恰好复现采集金额；
   - 已预缴税额 → 第 40 行。
3. **年份自适应**：表头按 JSON 实际申报年度升序重排（本例 2022/2023/2024）。

与 JSON 里"申报.列表"的应缴税款（−3216.41 / −1159.35 / 0.00）完全一致 ✓
